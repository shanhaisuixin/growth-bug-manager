行迹——人生Bug管理器

由于寡人多次不长记性，屡教不改，当我美美陷入「做了错、错了改、改了忘、忘了错」的循环之中时，每次都痛定思痛，懊悔不堪，然下次再犯。

故研究了数小时，制作了此物——人生Bug管理器，随时记下自己人生出现的Bug，并写下当下的想法与收获，可以看到自己成长的时间线，看到自己如何攻克一个个难题，确保它们不会再次被命运推到自己眼前，也希望能以此告诫自己:“前事不忘，后事之师

怎么用：首页点「今日记录」，上面写事件、下面写收获，点保存就完事。事件自动进「沉淀」的事件区，收获进收获区；「轨迹」里能看到一路走下来的时间线。

数据在哪：数据全部存于本地设备，不联网、不申请手机的任何一项权限、无账号登录功能。

故清理数据、卸载、换手机会导致数据丢失，请清理之前自行在设置页进行备份。

怎么装：安卓装 APK，iPhone 用 Safari 打开网页版后「添加到主屏幕」，电脑直接开网页。安装包在发布页。

网页版：<https://shanhaisuixin.github.io/growth-bug-manager/>
